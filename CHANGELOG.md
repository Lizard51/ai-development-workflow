# Changelog

## 1.0.0 — 2026-10-28

First public distribution of the existing AI Development Workflow skill.

- Includes the workflow entrypoint, model-routing and delivery references, UI metadata, and five project-document templates.
- Bundles the locally used Grilling and Domain Modeling snapshots with Matt Pocock's MIT notices.
- Adds Russian and English READMEs, installation guidance, illustrative prompts, contribution guidance, issue forms, and package validation on GitHub Actions.
- Removes a private pilot reference from the published routing introduction without making performance claims.
- Clarifies that fork options must match the runtime; removes an unsupported positive-number fork suggestion from the publication copy.

The installed local skills were not changed. This release adds distribution and documentation; it does not claim new end-to-end behavioral validation.
