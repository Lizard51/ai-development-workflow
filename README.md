## Что меняется в работе

Агент сначала изучает проект и уточняет решения, затем фиксирует договорённости. До реализации нового поведения он проверяет тесты на ожидаемое падение. Независимые задачи может передать подходящим субагентам, после чего проверяет их результат и весь затронутый сценарий.

| Принцип | На практике |
| --- | --- |
| Сначала договориться | Интервью по зависимым решениям и подтверждение общего понимания |
| Сделать работу видимой | Пять коротких документов в `.codex/` |
| Проверить до реализации | Тесты должны падать по ожидаемой причине; агент проверяет и сами ожидания |
| Делегировать по необходимости | Ограниченные задачи, явные профили моделей, изоляция параллельных изменений |
| Подтвердить результат | Проверка изменений, тестов и критериев приёмки координатором |
| Сохранить контроль | Git опционален; публикация и другие внешние действия требуют явного запроса |

## Быстрый старт

Попросите Codex установить комплект:

```text
$skill-installer Установи из репозитория Lizard51/ai-development-workflow
скиллы skills/ai-development-workflow, skills/grilling и skills/domain-modeling.
```

Затем начните задачу:

```text
$ai-development-workflow
Хочу приложение для учёта заказов небольшой мастерской.
Сначала изучи проект и помоги уточнить требования, затем доведи
согласованный объём до реализации и проверки.
```

Если скилл не появился, перезапустите Codex. Для ручной установки и установки только в один проект см. [инструкцию](docs/installation.md).

## Когда использовать

Подходит для нового приложения, крупной функции или изменений, где нужны требования, план и проверяемая приёмка. Для небольшой правки, отдельного объяснения или простого ревью полный процесс избыточен.

## Модели и ограничения

В поставляемом профиле рекомендован координатор `gpt-6.1-sol` / `high`; для ограниченных задач — `gpt-6-luna` / `medium`, для существенной реализации — `gpt-6.1-sol` / `medium`. Это рекомендации данного скилла, а не обещание доступности моделей в вашем аккаунте. Скилл сохраняет выбранного координатора и проверяет возможности среды. Если делегирование недоступно, работа остаётся у координатора либо используется явно обозначенная замена. [Подробная политика](skills/ai-development-workflow/references/model-routing.md).

Это набор инструкций, а не отдельный агентный движок. Он не добавляет инструменты и не гарантирует качество, экономию токенов или успешную сборку. Проверки репозитория подтверждают целостность пакета; они не заменяют приёмку конкретного продукта. [Что проверяется](docs/validation.md).
